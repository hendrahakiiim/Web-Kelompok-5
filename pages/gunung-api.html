PANDUAN KESIAPSIAGAAN GUNUNG MELETUS

Erupsi gunung api memuntahkan abu vulkanik, gas beracun, dan lahar panas. Patuhi radius zona bahaya yang ditetapkan pihak berwenang.

SEBELUM BENCANA

  • Pahami tingkat status gunung api (Normal, Waspada, Siaga, Awas).
  • Siapkan masker N95 dan kacamata pelindung (goggles) untuk mengantisipasi abu vulkanik.
  • Kenali jalur evakuasi dan lokasi pengungsian yang direkomendasikan PVMBG.

SAAT BENCANA

  • Segera evakuasi ke luar dari KRB (Kawasan Rawan Bencana) begitu ada instruksi.
  • Gunakan pakaian tertutup, masker, dan kacamata saat beraktivitas di luar ruangan.
  • Hindari daerah lembah atau aliran sungai untuk mengantisipasi bahaya lahar dingin.

SESUDAH BENCANA

  • Bersihkan atap rumah dari endapan abu vulkanik agar struktur atap tidak roboh.
  • Tetap gunakan masker hingga kondisi udara dinyatakan bersih dari abu vulkanik.
  • Ikuti petunjuk resmi mengenai waktu yang aman untuk kembali ke rumah.
