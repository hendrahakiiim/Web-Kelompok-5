Panduan Keselamatan Erupsi Gunung Api

Sebelum Bencana (Pencegahan & Persiapan)

  • Pahami batas Zona Bahaya Erupsi dan status aktivitas gunung api (Normal, Waspada, Siaga, Awas).
  • Siapkan masker (minimal N95) dan kacamata pelindung untuk mengantisipasi hujan abu.

Saat Bencana (Tindakan Darurat)

  • Gunakan masker dan pakaian tertutup untuk melindungi pernapasan dan kulit dari abu vulkanik.
  • Segera menjauh dari kawasan lembah/aliran sungai untuk menghindari bahaya lahar dingin/panas.

Setelah Bencana (Pemulihan & Evaluasi)

  • Bersihkan atap rumah dari timbunan abu vulkanik agar atap tidak ambruk karena beban berat.
