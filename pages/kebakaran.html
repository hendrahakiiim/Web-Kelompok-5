PANDUAN KESIAPSIAGAAN KEBAKARAN HUTAN & LAHAN

Kebakaran hutan dan lahan (karhutla) sering dipicu oleh musim kemarau panjang, aktivitas pembukaan lahan dengan cara dibakar, atau kelalaian manusia. Pahami langkah mitigasinya.

SEBELUM BENCANA

  • Hindari membakar sampah atau membuka lahan dengan cara dibakar saat musim kemarau.
  • Jangan membuang puntung rokok sembarangan di area hutan atau semak belukar.
  • Hindari membuat api unggun di area rawan atau pastikan api benar-benar padam sebelum ditinggalkan.
  • Sediakan stok masker minimal tipe N95 di rumah untuk mengantisipasi kabut asap.

SAAT BENCANA

  • Gunakan masker (seperti N95) saat keluar rumah untuk melindungi saluran pernapasan dari kabut asap.
  • Segera jauhi arah pergerakan api dan tiupan angin yang membawa titik api.
  • Tutup celah ventilasi rumah dengan kain basah untuk mencegah masuknya asap pekat.
  • Laporkan titik api awal (hotspot) kepada satgas karhutla atau pihak berwenang setempat.

SESUDAH BENCANA

  • Kurangi aktivitas luar ruangan sampai indeks kualitas udara (ISPU) dinyatakan aman.
  • Segera periksakan diri ke fasilitas kesehatan jika mengalami ISPA atau sesak napas.
  • Bantu pemulihan kawasan hutan dengan mendukung program reboisasi dan penanaman pohon kembali.
